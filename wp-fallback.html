IDLQR WordPress embed fallback

This page is a lightweight fallback for embedding or linking the full app at
https://barth-cyber.github.io/idlqr-app/

On Free WordPress plans the platform often restricts inline scripts. Recommended options:

  1. Link to the full app (open in a new tab): Open IDLQR
  2. If WordPress allows it, embed in a Custom HTML block using an iframe (example below). If WordPress sanitizes iframes, fallback to #1.

Iframe snippet (copy to a Custom HTML block)

<iframe src="https://barth-cyber.github.io/idlqr-app/" width="100%" height="900" style="border:0;" title="IDLQR"></iframe>

Download & host yourself

Alternatively, upload the static package located in the repo ZIP and host on any static host (GitHub Pages, Netlify, Vercel).

If you want, I can craft a WordPress page-ready HTML snippet with reduced content tailored for the WordPress editor instead of an iframe.
